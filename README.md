# UMKM Customer Segmentation

## Project Overview

This project aims to segment customers of a small and medium-sized enterprise (UMKM) using unsupervised machine learning techniques.

The objective is to identify customer behavior patterns and provide targeted marketing recommendations for each customer segment.

## Business Problem

The UMKM currently provides the same promotional offers to all customers. This project aims to improve marketing effectiveness by identifying different customer segments based on purchasing behavior.

## Dataset

The dataset contains customer information and transaction summaries from the last six months.

## Machine Learning Approach

- Unsupervised Learning
- Clustering
- K-Means (mandatory baseline)
- Gaussian Mixture Model (GMM)
- Agglomerative Clustering
- DBSCAN

## Project Workflow

1. Exploratory Data Analysis (EDA)
2. Data Cleaning
3. Feature Engineering
4. Data Preprocessing
5. Clustering Experiments
6. Model Evaluation
7. Customer Profiling
8. Model Deployment
